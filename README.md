# Colony Wars

## [Download the launcher for Windows (64-bit)](https://github.com/evan4yoo/ColonyWars-releases/releases/download/dev-0.1.0-1789779426/ColonyWarsLauncher.zip)

1. Download and extract the entire ZIP.
2. Open **ColonyWarsLauncher.exe** from the extracted folder.
3. Choose **Install**, then **Play**.

Keep the extracted files together. The launcher downloads the game for you.

Already have the launcher? Choose **Launcher update** in the left sidebar to get the newest launcher.

[Read the latest updates](https://github.com/evan4yoo/ColonyWars-releases/releases)
